# Arduino-Based Electronic Mosque Clock (Proteus Simulation)

## Overview
This project is a fully simulated Electronic Mosque Clock developed using Arduino Uno in Proteus. The system is designed to provide accurate time display with reliable data storage and efficient communication between hardware modules.

The project integrates RTC DS1307 for real-time clock functionality, EEPROM for saving settings after power loss, MAX7221 LED driver for display control, and UART communication for remote configuration and adjustment.

The entire system was successfully designed and tested in Proteus simulation environment.
